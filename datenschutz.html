2. Besuch der Website

Beim Besuch dieser Website können technische Daten verarbeitet werden, die für die Bereitstellung und Sicherheit der Website erforderlich sind.

Dazu kann insbesondere die IP-Adresse des verwendeten Endgeräts sowie technische Informationen über den Zugriff auf die Website gehören.

Die Website wird über GitHub Pages bereitgestellt. GitHub weist darauf hin, dass bei einem Besuch einer GitHub-Pages-Website die IP-Adresse des Besuchers aus Sicherheitsgründen protokolliert und gespeichert wird.

3. Zweck und Rechtsgrundlage

Die Verarbeitung technischer Zugriffsdaten erfolgt zur technischen Bereitstellung, Stabilität und Sicherheit der Website sowie zur Abwehr und Untersuchung von missbräuchlichen Zugriffen.

Die Verarbeitung erfolgt, soweit gesetzlich zulässig, auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO (berechtigte Interessen).

4. Warenkorb

Die Website verwendet den lokalen Speicher (localStorage) des Browsers, um den Inhalt des Warenkorbs auf dem Endgerät des Besuchers zu speichern.

Dabei werden ausschließlich die ausgewählten Produktkennungen und Mengen gespeichert. Es werden über diesen Warenkorb keine Namen, Telefonnummern, E-Mail-Adressen oder sonstigen direkten Kontaktdaten gespeichert.

Die Speicherung dient ausschließlich dazu, den Warenkorb auch nach einem Seitenwechsel oder einem erneuten Aufruf der Website verfügbar zu halten.

Der Warenkorb wird nicht automatisch an ZP Pyrotechnik übermittelt.

5. Unverbindliche Bestellanfrage

Wenn ein Besucher eine Bestellanfrage absendet, werden die von ihm im Formular eingegebenen Daten für die Bearbeitung der Anfrage verwendet.

Dabei können insbesondere folgende Angaben enthalten sein:

  • Name
  • Telefonnummer, sofern freiwillig angegeben
  • eine freiwillige Anmerkung
  • die ausgewählten Produkte und Mengen

Die Website fragt keine E-Mail-Adresse des Kunden ab.

Beim Absenden der Anfrage wird über den mailto:-Mechanismus des Browsers eine E-Mail mit den genannten Informationen vorbereitet. Die E-Mail wird nicht direkt von der Website an ZP Pyrotechnik versendet. Der tatsächliche Versand erfolgt über das vom Besucher verwendete E-Mail-Programm und erst nach dessen Bestätigung.

6. Zweck der Bestellanfrage

Die übermittelten Angaben werden ausschließlich zur Bearbeitung der unverbindlichen Bestellanfrage und zur anschließenden Kontaktaufnahme verwendet.

Die Bestellanfrage stellt keinen verbindlichen Kaufvertrag dar.

7. Keine Analyse- und Werbedienste

Diese Website verwendet derzeit keine Dienste wie Google Analytics, Google Ads, Facebook Pixel oder vergleichbare Analyse- und Werbetracking-Dienste.

Es werden auch keine externen Schriftarten, eingebetteten Karten oder Social-Media-Plugins verwendet.

8. Empfänger und Drittanbieter

Für den Betrieb der Website wird GitHub Pages als Hosting-Dienst verwendet.

Im Rahmen der Bestellanfrage kann der Besucher sein eigenes E-Mail-Programm bzw. seinen eigenen E-Mail-Dienst verwenden. Auf die dort stattfindende Datenverarbeitung hat ZP Pyrotechnik keinen unmittelbaren Einfluss.

9. Speicherdauer

Personenbezogene Daten werden nur so lange gespeichert, wie dies für die jeweiligen Zwecke erforderlich ist oder gesetzliche Aufbewahrungspflichten bestehen.

Die Speicherdauer von E-Mails mit Bestellanfragen richtet sich insbesondere nach den betrieblichen und gesetzlichen Erfordernissen von ZP Pyrotechnik.

Die im Browser gespeicherten Warenkorbdaten können vom Besucher jederzeit über die Einstellungen seines Browsers gelöscht werden.
